🧠 Quiz Game Project
Welcome to the Quiz Game project repository! This project is a fully interactive, lightweight web-based quiz application built using HTML5, CSS3, and Vanilla JavaScript.

This application is part of a beginner-friendly web development series featuring 100 HTML, CSS, and JavaScript projects designed to strengthen front-end development skills.

✨ Features
Interactive Start & Restart Screens: Clean UI transitions between the landing screen, active quiz session, and results screen.

Dynamic Question Rendering: Questions and options are loaded dynamically from a dedicated script dataset.

Score Tracking & Performance Feedback: Automatically evaluates user answers and delivers custom motivational messages based on final score percentages (e.g., Perfect, you're a genius! to Keep studying!).

Responsive Design: Works seamlessly across desktop, tablet, and mobile browsers.

🛠️ Tech Stack
HTML5: Semantic document structure (index.html).

CSS3: Custom styles, layouts, and modular UI states (style.css).

JavaScript (ES6+): Application logic, state management, event listeners, and DOM manipulation (script.js).

🚀 Getting Started
To get a local copy up and running, follow these simple steps:

Prerequisites
Make sure you have a modern code editor installed, such as VS Code. For the best development experience, it is recommended to install the Live Server extension in VS Code.

Installation & Setup
Clone or Download the repository:

Bash
git clone https://github.com/your-username/quiz-game.git
Navigate to the project folder:

Bash
cd quiz-game
Open the project in your editor:

Bash
code .
Run with Live Server:

Open index.html in VS Code.

Right-click and select "Open with Live Server", or click the Go Live button in the bottom right corner of your status bar.
